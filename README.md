# Учёт труб — постилажный учёт

Онлайн-версия: **https://aominewek.github.io/uchet-trub/**

Система складского участка ПАО «Сургутнефтегаз»: метраж и вес труб, адресное хранение, подготовка и отгрузка. Статическое приложение на HTML/CSS/JS — без бэкенда, CDN и внешних запросов. Данные хранятся в браузере (`localStorage`, ключ `utp_v3`), экспорт и импорт — JSON.

## Возможности

- **Метры и вес.** Вес считается по массе 1 п.м. из каталога (ГОСТ 632-80, 631-75, 633-80): метры × кг/м. Итоги показываются как «200 км 200 м», есть тонны, штуки и средняя длина.
- **Территории.** По умолчанию «Белый Яр»; новые территории и зоны добавляются в админке.
- **Оргединицы.** ЦБТ, ЦОТ, ЦНКТ, ЦПРР с расшифровкой в скобках; можно добавлять свои.
- **Зоны.** Стеллажи по 10 ячеек, автокрановая площадка временного хранения ПВХ, цех.
- **Несколько ячеек.** Одна операция может занимать ячейки Я01, Я02, Я03 — выбор чипами.
- **Карта склада.** Фильтр «оргединица + диаметр» показывает, где лежат остатки; ячейки окрашиваются по заполненности: зелёный → оранжевый → красный, с меткой «заполнено».
- **Подготовка.** Завод → стеллаж (не подготовленная) → цех (подготовленная) → стеллаж → погрузка → отгрузка в подразделение (расход).
- **Отчёты.** Движение за период, остатки по оргединицам и типоразмерам, цикл подготовки, заполненность зон, активность сотрудников, печать.
- **Права.** Роли «Администратор», «Начальник участка», «Кладовщик», «Наблюдатель»; индивидуальные права выдаются в разделе «Пользователи».
- **Прочее.** Уведомления, профиль, журнал действий, проверки данных, поиск.

## Демо-вход

Пароль — табельный номер.

- Иванов И.П. — **1001** (администратор)
- Петров А.С. — **1002** (начальник участка)
- Сотрудники 1003–1050 — кладовщики и мастера
- Руководитель — **9999**

## Запуск

- Онлайн: открыть ссылку выше.
- Локально: открыть `index.html` в Edge/Chrome или отдать папку статическим сервером.
- Сборка одного файла: `node site.cjs bundle uchet-trub-site/index.html uchet-trub.html`.

## Ограничение

Однопользовательский режим: у каждого браузера своя база. Для совместной работы нужен серверный вариант с общей базой и настоящей авторизацией.
