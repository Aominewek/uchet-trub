# Учёт труб — постилажный учёт

Онлайн-версия: **https://aominewek.github.io/uchet-trub/**

Система складского участка ПАО «Сургутнефтегаз»: метраж и вес, номенклатурные номера, адресное хранение, подготовка и отгрузка. Статическое приложение на HTML/CSS/JS — без бэкенда, CDN и внешних запросов. Данные хранятся в браузере (`localStorage`, ключ `utp_v4`), экспорт и импорт — JSON.

## Возможности

- **Номенклатурный номер.** Обязателен для каждой позиции; виден в каталоге, форме операции, реестре, остатках и на карте.
- **Метры и вес.** Вес считается по массе из каталога: метры × кг/м для труб, штуки × кг/шт для прочих изделий. Итоги — «200 км 200 м», тонны, штуки, средняя длина.
- **Не только трубы.** Позиции бывают разных типов: труба, ПВХ, металлопрокат, запчасти, прочее; единица учёта — метр или штука. Стеллажи и ячейки общие.
- **Территории.** По умолчанию «Белый Яр»; новые территории и зоны добавляются в админке.
- **Оргединицы.** ЦБТ, ЦОТ, ЦНКТ, ЦПРР с расшифровкой в скобках; можно добавлять свои.
- **Зоны.** Стеллажи по 10 ячеек, автокрановая площадка временного хранения ПВХ, цех.
- **Несколько ячеек.** Одна операция может занимать Я01, Я02, Я03; в форме видно занятость и свободный объём каждой ячейки.
- **Карта склада.** Фильтр «оргединица + диаметр»; при наведении — состав ячейки, по клику — подробности: позиции, номенклатурники, статус, метры, штуки, вес.
- **Подготовка.** Завод → стеллаж (не подготовленная) → цех (подготовленная) → стеллаж → погрузка → отгрузка в подразделение (расход).
- **Точечные обновления.** Фильтры остатков, поиск, карта и уведомления обновляют только свою область, без перерисовки всей страницы.
- **Отчёты.** Движение за период, остатки по оргединицам и типоразмерам, цикл подготовки, заполненность зон, активность сотрудников, печать.
- **Права.** Роли «Администратор», «Начальник участка», «Кладовщик», «Наблюдатель»; индивидуальные права — в разделе «Пользователи».
- **Прочее.** Уведомления, профиль, журнал действий, проверки данных, поиск.

## Демо-вход

Пароль — табельный номер.

- Иванов И.П. — **1001** (администратор)
- Петров А.С. — **1002** (начальник участка)
- Сотрудники 1003–1050 — кладовщики и мастера
- Руководитель — **9999**

## Запуск

- Онлайн: открыть ссылку выше.
- Локально: открыть `index.html` в Edge/Chrome или отдать папку статическим сервером.
- Сборка одного файла: `node site.cjs bundle uchet-trub-site/index.html uchet-trub.html`.

## Данные

`localStorage`, ключ `utp_v4`; база версии 3 переносится автоматически. Резервная копия — «Экспорт JSON».

## Ограничение

Однопользовательский режим: у каждого браузера своя база. Для совместной работы нужен серверный вариант с общей базой и настоящей авторизацией.

## Публикация

Репозиторий публичный, сайт раздаётся GitHub Pages из ветки `main`.
