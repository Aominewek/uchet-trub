# Учёт трубной продукции — веб-приложение

Офлайн-приложение складского участка: реестр операций, остатки по адресам (10 территорий × 5 стеллажей × 10 ячеек + цех), живая схема склада, отчёты, поиск и контроль данных.

Полностью статическое: HTML + CSS + JS, без бэкенда, CDN, внешних шрифтов и сетевых запросов. Данные хранятся в `localStorage` браузера; экспорт/импорт — JSON.

## Демо-вход

Сотрудник из списка, табельный номер **1001**. Руководитель — **9999**.

## Локальный запуск

Открыть `index.html` в браузере (Edge/Chrome). Либо отдать папку любым статическим сервером.

## Онлайн-версия

Сайт опубликован на GitHub Pages: **https://aominewek.github.io/uchet-trub/**

Открывается в любом браузере. Интернет нужен только для загрузки страницы — данные остаются в браузере и на сервер не уходят.

Репозиторий публичный: код и приложение видны всем. Реальных данных в нём нет, только демонстрационные записи.

## Данные

`localStorage`, ключ `utp_v2`. Резервная копия — кнопка «Экспорт».

## Ограничение

Однопользовательский режим: у каждого браузера своя база. Для общей работы нужен серверный вариант с базой.
